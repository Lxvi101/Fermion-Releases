# Fermion releases

This repository hosts public macOS installers for Fermion. It contains no user accounts, credentials, local catalogs, workspace contents, or source history.

Installers are signed with the Fermion Developer ID certificate and notarized by Apple before publication. Download the latest release from this repository's Releases page. Check the app's signature and Gatekeeper status before running it.

The Fermion source repository is maintained separately.
